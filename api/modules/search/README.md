# Поиск

[Карта API](../../README.md) · [Документы](../documents/README.md)

Отдельный раздел `/search` ищет сведения в доступных документах. Новых таблиц,
зависимостей или внешних сервисов нет. Логика находится в [router.py](router.py).

## Поведение

- `GET /api/search?q=...` требует `documents.view` и использует общую проверку `can_view()` документов.
- Все слова должны присутствовать в совокупности названия и извлечённого текста. Регистр не учитывается.
- Слова ищутся как подстроки; морфологии, исправления опечаток и поиска по смыслу нет.
- Больше совпадений слов в названии — выше результат; при равенстве сначала новые документы.
- Ответ содержит ID, название, формат, автора, дату, состояние и фрагмент текста до 280 символов плюс многоточия.
- Пустой запрос возвращает пустой список. Максимальная длина — 200 символов.
- Таблицы участвуют через текстовую копию, созданную при извлечении. Оригинальные файлы заново не читаются.
- Документ с ошибкой чтения можно найти по названию; фрагмент текста в этом случае пуст.

Проверка доступа выполняется до поиска. Недоступные документы не включаются в результаты и фрагменты.
Изменение получателей или роли пользователя учитывается при следующем запросе.
Поиск выполняется в Python по данным SQLite, без индекса и пагинации; рассчитан на небольшой набор документов.

## Интерфейс

`frontend/src/modules/search/SearchPage.tsx` содержит форму, состояния загрузки/ошибки и результаты.
Совпадения выделяются React-элементами `mark`; содержимое документа не интерпретируется как HTML.
Запрос сохраняется в URL. Ссылка на карточку передаёт `from=search` и `q`, чтобы вернуться к той же выдаче.
Повторная отправка того же запроса обновляет результаты; после ошибки доступна кнопка «Повторить».

Страница поиска отключена в текущей конфигурации интерфейса, так как в меню выключен раздел
документов, к карточке которого ведут результаты. Сам серверный роутер остаётся подключён
в `api/main.py` и проверяет права пользователя.

API-проверки: [test_search.py](../../tests/test_search.py). Команды запуска тестов находятся
в [руководстве по разработке](../../../docs/development.md#проверки).
